# React Portfolio

A personal portfolio website built with **React.js**, showcasing my projects, blogs, and skills.  
Deployed on **Netlify** for fast and reliable hosting. The blog CMS is powered by **Sanity**.

## 🌐 Live Demo
Check it out here: [https://vishwasjha.com](https://vishwasjha.com)

## 🚀 Features
- Blog CMS system using **Sanity.io**
- Fully responsive design for all devices
- Dark theme toggle
- Smooth animations for interactive elements
- Easy to customize and extend

## 🛠️ Tech Stack
- **Frontend:** React.js, Vite
- **Styling:** CSS / Tailwind
- **CMS:** Sanity.io
- **Backend Functions:** Netlify Functions
- **Other Tools:** Notion (for planning & content management)
